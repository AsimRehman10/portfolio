Share logic via KMP. Keep UI native.

The rule that decides where every line of code goes.

commonMain

Business rules, networking, persistence, validation and state — written once in Kotlin, tested once, shipped to both platforms without translation.

Jetpack Compose

Android's surface stays Android — Material You conventions, system biometrics, edge-to-edge, recomposition tuned by hand rather than inherited from a shared widget tree.

SwiftUI

iOS gets the same treatment in the other direction — Keychain-backed storage, native device authentication, and a feel that never betrays a shared codebase underneath.
